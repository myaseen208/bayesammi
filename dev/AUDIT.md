## Findings (by hand)

Read against Crossa et al. (2011), Crop Science 51:1458-1469 (conditionals eq. 5-10, Appendix A). The old sampler
cannot be run here (rstiefel is not installable without CRAN access); the findings come from the code.

### bayes_ammi(): the Gibbs sampler

1. **The singular values are never sampled.** `lambdas_m` is computed once before the loop and every iteration sets
   `lambdas <- lambdas_m`, so `lambdas1` is a constant chain. Its formula sums `alphas %*% t(gammas) * ge_means` over
   all components (a scalar) instead of `alpha_k' Y gamma_k` for each k.
2. **The error variance is not returned.** `tau1` stores `tau`, the precision of the least-squares start, which never
   changes; the sampled `sigma2` is never stored. The example plots `tau1` as sigma^2: a flat line.
3. **Residuals for sigma^2 compare the wrong cells.** `matriz_desv_model()` selects environment `Envs[iter2]`, the
   environment of data row `iter2`, not the `iter2`-th environment; with `Maiz` (sorted by site) every column is
   compared with site 1. Genotypes are matched with `df1$Gen == iter`, which works only when the labels are 1..g.
4. **Within-cell sum of squares.** `ssy` adds the within-cell variances instead of the sums of squares
   ((r - 1) times the variances).
5. **Covariances of tau and delta.** `MASS::mvrnorm()` receives the square root of the variance as `Sigma`; the
   delta conditional uses r e (genotype count of the wrong factor) instead of r g.
6. **Scores.** `rmf.matrix.gibbs4()` loops over `r <- 1:R` (all columns at once, so the null space of `Y[, -r]` is
   empty), samples on the full Stiefel manifold and then forces orthogonality to 1 by Gram-Schmidt: not a draw from
   the constrained conditional (eq. 8-9). The parameter matrix uses the raw cell means.
7. **Sign alignment** tests `alphas` where `gammas` is meant (`sgn4`).
8. **All interaction axes** (min(g, e) - 1) are fitted; the paper fits two.
9. **Improper prior for sigma^2** (`alfa_sig_ap = beta_sig_ap = 0`), which Hobert and Casella (1996) warn against
   (the paper uses nu = 1).
10. **No burn-in, no chains, no seed**; output `alphas1`/`gammas1` built with `rep(1:g, times = .nIter)` recycled into
    g rows.

### biplots()

11. Contours of the raw singular vectors, not of the biplot coordinates lambda^(1/2) alpha of the paper; a fixed
    kernel bandwidth h = 0.2 whatever the scale; `thin` is a proportion inverted to a step; the environment columns
    are labelled `alpha`; "stable" is decided by the bounding box of a contour, not by whether the region contains
    the origin.

### Other functions

12. `ge_model()` fits `lme4::lmer()` for the error variance; with balanced data it equals the residual mean square of
    the randomized complete block model (closed form).
13. `Maiz` help page: 1320 rows and columns Gen, Institute, Rep, Block, Env, Yield; the data have 720 rows and columns
    site, entry, fold10, rep, y, fold5, fold3 (9 genotypes, 20 sites, 4 replicates).
14. Help pages without details or maths; dependencies on the tidyverse (dplyr, tidyr, tibble, purrr, magrittr,
    rlang) and on rstiefel, tmvtnorm, mvtnorm, ks, lme4 that the corrected code does not need.

### Published values for validation

Crossa et al. (2011), Table 1 (posterior means, SD, 95% HPD of mu, sigma^2, tau_i, delta_j, lambda_1, lambda_2) and
Table B1 (alpha_ik, gamma_jk, k = 1, 2); least-squares lambda 5923 and 3070 (text), reproduced exactly by the data.
